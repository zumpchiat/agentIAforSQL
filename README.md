# agentIAforSQL

### Descrição

Este projeto tem como objetivo desenvolver um agente de Inteligência Artificial capaz de compreender linguagem natural e traduzi-la em consultas SQL. Utilizando técnicas de NLP (Processamento de Linguagem Natural) e modelos de linguagem, o agente facilita o acesso a dados em bancos relacionais sem a necessidade de conhecimento técnico em SQL por parte do usuário. A aplicação é útil em contextos como painéis analíticos, suporte a tomadas de decisão e sistemas de informação.
